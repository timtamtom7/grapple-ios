# Grapple

An AI thinking partner that challenges your ideas. Paste a thought or plan; Grapple finds the strongest counter-arguments and tests it from every angle. Rigorous, not contrarian.

## Concept

- Paste a thought, belief, plan, or piece of writing
- Strongest counter-arguments, not nitpicks
- Multi-angle challenge
- Citations for every argument
- Accessibility schemes

## Targets

- iOS
- iPadOS
- macOS
- watchOS

## Stack

- SwiftUI
- Apple Intelligence
- XcodeGen

## Structure

The widest target spread in the batch: `Sources/` (iOS), `MacSources/`, `WatchSources/`, plus `Resources/` and `AppStoreAssets/`. Key types: `AIService`, `AccessibilitySchemes`, `ArgumentCard`, `Citation`/`CitationView`.

Version 1.0.
